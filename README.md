# Ereku David — Portfolio

Static portfolio built with HTML, CSS and JavaScript.

## Run
Open `index.html` in a browser or use VS Code Live Server.

## Deploy
Works on Vercel, Netlify or GitHub Pages.

## Projects

The portfolio includes NEO, The Hive Lounge, Palm Resto Lounge, Blue Pepper, Cedar House, Swift Pick Mall and Silverdale Schools. Live deployment links are included for NEO and the four newer Vercel projects. The GitHub profile linked from the portfolio is [Sindex4](https://github.com/Sindex4).

It also includes a Face Recognition project card, linked to its GitHub source. This project is intentionally described as local/backend-dependent: deploy its Python runtime, model files, dependencies and any API service separately before linking it to a public demo. It should not be represented as a Vercel-only deployment.
